#   Supermarket Cashier System

## Description:
Supermarket Cashier System is my first complete python project, built from scratch as part of my programming jorney. The goal of this project is to simulate the the basic workflow of a real supermarket cashier system while improving my python skills through practical development.
The project is still under active devlopment, and I plan to continue adding new features and improving the code as I learn more.

---

## Project Goals:
- Build my first complete python application.
- Practice writing clean, organized, and maintainable code.
- Apply python concepts to a real-world project.
- Continuously improve the project by adding new features and refining the existing once.

## Current & Planned Features:
- Secure login system.
- User authentication with limited login attempts.
- Display available supermarket products.
- Purchase one or multiple products.
- Supermarket wllet/balance management.
- Discount system
- Automatic receipt generation.
- Final price calculation.
- Input validation and error handling.
- Cleaner and more organized program structure.
- Product search system *(planned)*
- Additional improvement and features in future updates.
